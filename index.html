      유형별 학습 분석

        무료 체험 · 요금제 안내

        출시 전 미리보기입니다. 가격·결제사·환불 정책은 미확정이며 실제 결제나 구독 권한이 발생하지 않습니다.

        무료 체험

        정식 서비스는 7일 무료 체험을 계획하고 있습니다. 현재 체험 기간을 실제 계정에 적용하지 않습니다.

        결제, 자동 갱신, 해지, 환불은 아직 제공되지 않습니다.

        운영 준비 현황

        현재 준비 항목만 표시합니다. 실제 운영 기능은 제공되지 않습니다.

          회원가입·로그인

          로그인 계정:

          학생 프로필 · 학년 설정

          학년을 선택하고 저장하면 다음 로그인 때에도 유지됩니다.

          학부모 · 자녀 연결

          학생은 학년 저장 후 코드를 발급하고, 학부모는 전달받은 코드로 자녀를 연결합니다.

            학부모 학습 현황

            자녀별 학습 기록은 서버 연동 후 제공됩니다.

            실제 연결은 학생 계정에서 발급한 일회성 코드를 학부모가 입력하고 서버가 검증한 뒤에만 가능합니다.

            회원 정보 변경

            로그인한 본인 계정만 변경할 수 있습니다. 이메일 변경에는 인증 메일 확인이 필요할 수 있습니다.

            회원 탈퇴

            탈퇴 기능은 아직 실행할 수 없습니다. 승인 없이 계정이나 학습 데이터를 삭제하지 않습니다.
